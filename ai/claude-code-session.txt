❯ how do you know you cant apply both coupons? they are different               
● The spec says so directly. In SPEC.md, under "Discount coupons":

  ▎ Discounts are applied with a code: only one per purchase. If a coupon is 
  ▎ already applied, another one can't be added (the current one must be removed
  ▎ first).

  So it doesn't matter that FLOCK10 and BIENVENIDA15 are different codes. Only
  one coupon can be on a purchase at a time, whichever it is.

  The app's own code agrees, which is why I'm confident it's a bug and not just
  my reading:
  - If you apply FLOCK10 and then try BIENVENIDA15 without reloading, the cart
    blocks it with "Only one coupon can be used per purchase." The developers
    meant to enforce the rule.
  - The check breaks on reload (BUG-07): the flag that tracks "a coupon is
    already applied" resets on every page load, even though the coupon itself is
    still saved in the cart.
  - The server never enforces the rule (BUG-06): it accepts any number of
    coupons and adds their discounts together.

  You can see the first point yourself in the browser. Apply FLOCK10, then
  BIENVENIDA15 without reloading, and you'll get the error. Reload the page, try
  BIENVENIDA15 again, and both get applied.

  One related thing the spec doesn't cover is whether the same coupon could
  count twice. The "one per purchase" rule rules that out anyway, which is why
  BUG-06 also tests ["FLOCK10","FLOCK10"].
